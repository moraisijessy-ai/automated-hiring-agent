# 🤖 AI Safety Talent Sourcing Agent

> Retrieve, evaluate, and rank AI safety researchers in the UK/US — with emphasis on scheming, deceptive alignment, and related risks.

---

## 🎯 What This Does

This project provides a prompt template and output schema for an AI agent (e.g., Claude) that:
- Searches for researchers working on AI safety topics
- Filters for UK/US-based individuals with recent, relevant output
- Ranks candidates by topical relevance (direct > adjacent topics)
- Outputs structured, validated JSON for downstream use
