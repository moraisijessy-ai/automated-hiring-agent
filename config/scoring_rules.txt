AI SAFETY RESEARCHER SCORING GUIDE
==================================
Version: 1.0 | Last Updated: 2026

This document explains how relevance scores (0.0–1.0) are calculated.
Use this for manual review or prompt tuning.

─────────────────────────────────────
1. BASE SCORE BY TOPIC CATEGORY
─────────────────────────────────────

DIRECT TOPICS (Base: +0.30 to +0.50)
✓ scheming
✓ deceptive alignment
✓ strategic deception
✓ power-seeking behaviour
✓ hidden objectives
✓ situational awareness

ADJACENT TOPICS (Base: +0.15 to +0.25)
✓ AI control
✓ monitoring systems
✓ oversight
✓ model organisms of misalignment
✓ goal misgeneralisation
✓ alignment evaluations

→ Researchers with work in BOTH categories: use the higher base score.

─────────────────────────────────────
2. RECENCY MULTIPLIER
─────────────────────────────────────

Apply multiplier to base score based on most recent relevant work:

• 2024–2026: ×1.0 (full credit)
• 2021–2023: ×0.9 (slight decay)
• 2018–2020: ×0.7 (significant decay)
• Before 2018: ×0.4 (only include if highly influential)

─────────────────────────────────────
3. EVIDENCE QUALITY BONUSES
─────────────────────────────────────

+0.10  Peer-reviewed paper at top venue (NeurIPS, ICML, ICLR, etc.)
+0.05  Preprint on arXiv with >50 citations
+0.05  Technical post on Alignment Forum / LessWrong with strong engagement
+0.05  Open-source tool or dataset relevant to target topics
+0.03  Each additional piece of qualifying evidence (max +0.15 total)

─────────────────────────────────────
4. CONFIDENCE ADJUSTMENTS
─────────────────────────────────────

Reduce final score if:
- Location is inferred, not explicit: −0.05
- Affiliation is outdated or ambiguous: −0.05
- Topic match relies on single keyword mention: −0.10
- No direct link to full text/abstract: −0.05

Flag as confidence="low" if total deductions ≥0.15.

─────────────────────────────────────
5. FINAL SCORE CALCULATION
─────────────────────────────────────

formula:
  final_score = min(1.0, (base_score × recency_multiplier) + evidence_bonuses − confidence_deductions)

examples:
  • Direct topic (0.45) × recency (1.0) + evidence (0.10) = 0.55 → score: 0.55
  • Adjacent topic (0.20) × recency (0.9) + evidence (0.05) − ambiguity (0.05) = 0.18 → score: 0.18

─────────────────────────────────────
6. RANKING ORDER (TIE-BREAKERS)
─────────────────────────────────────

1. relevance_score (descending)
2. topic_category (direct > adjacent)
3. most recent evidence year (newer first)
4. alphabetical by name (for deterministic ordering)

─────────────────────────────────────
7. WHEN TO EXCLUDE
─────────────────────────────────────

Do NOT include a researcher if:
• No verifiable UK/US affiliation
• No relevant work published 2021–2026
• Work is purely policy/governance with no technical content
• Only tangential keyword match (e.g., "alignment" in abstract but not core focus)
• Duplicate of another entry (prefer most recent affiliation)

─────────────────────────────────────
REVIEW CHECKLIST (for human validators)
─────────────────────────────────────

[ ] Affiliation verified via institutional page or recent publication
[ ] At least one evidence URL is accessible and on-topic
[ ] Topic category correctly assigned (direct vs. adjacent)
[ ] Confidence level matches evidence quality
[ ] No PII or sensitive data included in output
